This is a Simple wallpaper picker for Linux

You'll require feh, fzf applications to make it work. You'll need something to render the image on the terminal as well. For example, if you are using Kitty, it has image protocols built-in, but if you are using Alacritty or something else, you will require Ueberzugpp to render the image, or if you are fine with pixelated previews, you can use chafa.

This is helpful if you are using any window manager particularly. I'm using i3 window manager.
